# Eval-сценарии LearnOS (T-050 Э6, раздел F аудита)

«Золотые» сценарии поведения агентов: гоняются на **живой модели** раннером
`server/scripts/run_evals.py` (в pytest не входят — не хотят FakeLLM).

```bash
cd server && sec exec ZAI_API_KEY -- uv run python scripts/run_evals.py [имя-фильтр]
```

Формат файла:

```yaml
name: уникальное-имя          # привязка к фильтру запуска
agent: quick_reviewer         # кто ведёт (из реестра агентов)
user: "текст пользователя"    # единственное сообщение
system_extra: "…"             # опционально: контекст-блок (источник/глава)
expect:
  tools_any: [show_chapter_review]      # хотя бы один из инструментов должен быть вызван
  tools_none: [save_note]               # эти вызывать нельзя
  cards_any: [chapter_review]           # карточка типа должна прийти
  text_contains: ["##"]                 # (опц) в финальном тексте
  text_not_contains: ["Главное:"]       # (опц) в финальном тексте
```

Проверяются контракты из аудита: разбор глав — карточкой (не простынёй), конспект —
только через превью-апрув, сессия — вопросы фейнмана через advance(ask), окна
read_chapter читаются до next_offset=null, рекомендации по добавлению источников —
только карточкой offer_action.

Контракт файлов (yaml/поля/агенты/инструменты) валидируется обычным тестом
`tests/unit/evals_contract_test.py` — сломанный сценарий ловится в pytest и CI.
