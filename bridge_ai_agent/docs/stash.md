# Склад (stash) — хранилище ресурсов для нейронок (решение 2026-11-17)

## Зачем
Ссылки на скиллы, MCP, репо, сервисы, каталоги копятся в Telegram «Избранном». Нужен склад, откуда
нейронки (скилл-менеджер `radmipa-skills`, Claude, OpenCode, агенты LearnOS) берут ресурсы по задаче.
Скилл-менеджер сам решает, как интегрировать: LearnOS только хранит, индексирует и проверяет живость.

## Граница с библиотекой
- Библиотека — «прочитать и понять» (книги, статьи, видео) — для человека, участвует в обучении.
- Склад — «взять и использовать» (репо, скилл, MCP, сервис, каталог) — для нейронок; в KB/повторения не идёт.
- При сохранении нейронка сама выбирает место; на карточке «Перенести в библиотеку / на склад».

## Карточка (путеводитель, не пересказ)
`url, title, category, tags[], summary (1–2 предл.), where[] ("нужно X → раздел/URL"), install (команда, если есть),
use_when (когда пригодится), note (пометка пользователя «почему сохранил»), liveness {status, http, checked_at,
repo: stars, pushed_at, archived}, parent_id (для развёрнутых каталогов), source (chat|share|mcp|import)`.

Категории — фиксированные: skills · mcp · rules (правила/промпты) · agents (агенты/фреймворки) ·
ui (компоненты) · tools (инструменты/сервисы) · datasets (датасеты/тренировки) · catalogs. Внутри — свободные теги.

## Эталон разбора (designbookmark.com, 2026-11-17)
Каталог 2 868 инструментов / 59 категорий; `/skills` — 50 скиллов с GitHub-репо и командой установки;
`/ai/agent-skills` — реестры скиллов и MCP; `/motion` — ~84 анимированных компонента. Живой (200, обновления Nov 16).
Вывод: каталоги нужно уметь **разворачивать** в дочерние карточки (каждый скилл → своя карточка с репо и install).
