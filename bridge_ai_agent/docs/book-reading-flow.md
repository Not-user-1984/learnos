# Путь «книга → глава → разбор → база → закрепление» (решение 2026-11-17)

## Как сейчас (факты разведки)
- Два PDF-режима дублируются: `/library/[uid]/read` (полноэкранный, без чата и кнопок) и
  `/library/[uid]/[chapter]?mode=pdf` (с чатом, без оглавления/клавиатуры/места). Оба — `PdfViewer`, только canvas,
  без text-layer → цитировать из PDF нельзя.
- Место чтения — только в URL (`?ch=&page=`), сервер не знает; ридер не зовёт mark-read → книга не попадает в «Сегодня».
- Блок KB рождается только из сессии-урока. Обсуждение главы и «Быстрый разбор» блоков не создают.
- Повторение — SM-2 на блок целиком; карточек нет; набора «по книге» нет (очередь глобальная).

## Целевой путь (одинаков для «прочитал сам» и «разбираю без чтения»)
1. **Читаю** — один ридер `/library/[uid]/read`: PDF с text-layer, оглавление, место на сервере
   (activity: chapter + page), справа чат главы (шторка на мобиле), выделение → цитата в чат.
2. **Глава прочитана** — кнопка или авто при переходе на следующую главу → mark-read + предложение
   «Разобрать главу» (можно пропустить).
3. **Разбор главы** — разговор главы (уже есть, B-006). Можно начать сразу, не читая (режим «разбираю»:
   нейронка ведёт по главе сама).
4. **Записать в базу** — в разговоре главы: мини-фейнман (1–2 вопроса «перескажи суть своими словами»)
   → блок `verified`, `block_sources=(source, chapter)`, + 3–5 **карточек-сути**. Правило «знание = только
   через проговор» сохранено, но без тяжёлой сессии.
5. **Закрепляю** — карточки по SM-2 (каждая отдельно); «Набор по книге» = карточки всех блоков источника;
   «Выжимка книги» = по 3 тезиса на главу. Напоминания — через существующий review_digest.

## Карточка-суть (правило «мякотки»)
- Вопрос → короткий ответ (≤2 предложения), одна идея на карточку, 3–5 на главу.
- Только то, что пользователь проговорил/подтвердил в разборе; без примеров, истории, воды.
- Пользователь может удалить/поправить карточку на странице блока.

Задачи: B-012 (баги), B-013 (чтение и разбор), B-014 (закрепление).
