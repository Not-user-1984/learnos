# B-006 · Читаю/смотрю и обсуждаю рядом: split-view книга|видео + чат, таймкоды

Цель: глава книги или видео открыты слева, разговор с нейронкой о них — справа, без ухода со страницы.
Цитата из текста и момент видео одним действием попадают в чат. Нейронка ссылается на таймкоды, клик
по таймкоду перематывает видео.
Контекст: `docs/system-review-2026-11.md` §3 (последний пункт); `docs/youtube-subtitles.md`.

## Готово, когда
- [ ] `/library/[uid]/[chapter]` на ≥1024px: читалка слева, панель чата справа (сворачиваемая); на мобиле —
      чат выезжающей шторкой снизу.
- [ ] Разговор привязан к (source, chapter): повторное открытие главы продолжает тот же разговор; агент получает
      контекст главы (через `read_chapter`, не целиком в промпт).
- [ ] Выделение текста → «Обсудить» вставляет цитату в композер панели (не уводит на `/chat`).
- [ ] Видео-источник: YouTube-плеер (iframe API) + транскрипт с таймкодами; кнопка «Спросить про этот момент»
      вставляет `[мм:сс]` и фрагмент транскрипта ±30 с.
- [ ] Таймкоды `[мм:сс]`/`[ч:мм:сс]` в ответах ассистента кликабельны → seek плеера.
- [ ] Старые видео без таймкодов работают как раньше (текст без плеера-синхронизации).

## Изменения
1. **Сервер, видео-тайминги**: `run.py` дополнительно пишет сегменты `[{start: float, text}]` (из cue VTT,
   склейка по ~4 реплики как сейчас) в `data/youtube/<id>.segments.json`; library сохраняет путь в метаданных
   главы/источника. REST `GET /api/sources/{ref}/segments?from=&to=`.
2. **Сервер, разговор главы**: `GET|POST /api/sources/{ref}/chapters/{idx}/conversation` — get-or-create
   разговора (поле `context_ref` у conversation: `source_uid`,`chapter_idx`; миграция). Системная директива
   для такого разговора: «обсуждаем главу N источника X, читай её через read_chapter; таймкоды пиши [мм:сс]».
3. **Web**: вынести из `chat-view.tsx` переиспользуемый `ChatPanel` (лента + композер + NextSteps из B-003)
   без шапки/истории; `chat-view` использует его же. Читалка рендерит `ChatPanel` справа.
4. **Web, видео**: компонент `video/youtube-player.tsx` (IFrame API, без внешних библиотек) + `transcript.tsx`
   (подсветка текущего сегмента, клик → seek). Markdown-рендер: плагин, превращающий `[мм:сс]` в кнопку seek,
   активен только в ChatPanel видео-источника.
5. **Мобила**: панель чата — существующий `ui/dialog`/sheet, не самописная модалка.

## Тесты
- server: парсер сегментов на фикстуре VTT (тайминги монотонны, текст совпадает с `_parse_vtt`);
  get-or-create разговора главы идемпотентен.
- web: tsc/lint/build; ручная проверка в preview: книга (выделение → цитата в панели), видео (seek по таймкоду).

## Риски
- Делать после B-003 (тот же `chat-view.tsx`). Разрез `ChatPanel` — без изменения поведения основного чата.
