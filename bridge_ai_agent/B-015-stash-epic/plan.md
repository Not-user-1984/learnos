# B-015 · Эпик «Склад»: хранилище ресурсов для нейронок

Цель: ссылки на скиллы/MCP/репо/сервисы сохраняются одним действием, нейронка делает карточку-путеводитель,
раскладывает по категориям, проверяет живость; любой агент (скилл-менеджер radmipa-skills) находит ресурс
по задаче через MCP. Дизайн и эталон разбора: `docs/stash.md`. Брать после ревью B-012…B-014.

## Этапы (каждый — отдельный коммит, проверки зелёные после каждого)
1. **Модуль `modules/stash/`** (domain/service/infra/api/tools/events, своя миграция): карточка по `docs/stash.md`,
   дедуп по нормализованному URL, фиксированные категории + теги. Не связан с library/knowledge (только events/public).
2. **Разбор (job в JobWorker)**: GitHub → `github_repo`/`github_file` (README, звёзды, pushed_at, archived);
   прочее → `web_read`. LLM-роль `structured` заполняет карточку; классификация «склад или библиотека»
   (если библиотека — `add_source` и карточка-ссылка). Эмбеддинги карточки — в гибридный поиск (B-008).
3. **Каталоги**: `expand(id)` — дочерние карточки из разделов каталога (лимит 50 за раз, по запросу, не авто).
4. **MCP**: в `/mcp/brain` — `stash_add(url, note?)`, `stash_search(task, category?, alive_only=true, limit)`,
   `stash_get(id)`, `stash_expand(id)`. Ответ search компактный (title, summary, install, use_when, url, liveness).
5. **Живость**: расписание `stash_liveness` (планировщик B-010, раз в неделю): HTTP-статус, для репо — archived/pushed_at;
   статусы alive / stale (>12 мес без коммитов) / dead. Мёртвые не удаляются.
6. **Web**: раздел «Склад» в навигации; категории → сетка карточек с бейджем живости, пометкой, install (копировать);
   поиск; «Развернуть каталог», «Перенести в библиотеку», удалить/поправить.
7. **Ввод**: «сохрани это» в чате (тул root-агента), `/share` с телефона определяет склад/библиотеку,
   импорт текста экспорта Telegram (`POST /api/stash/import` — текст/JSON: из поста ссылки, текст поста → note).
8. **Подсказки в чате**: root-агент при теме разговора делает `stash_search` и предлагает 1–3 релевантных ресурса
   (не чаще раза за разговор на тему).
