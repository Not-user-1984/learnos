# B-005 · Главная «Сегодня» + курс как доска + страница повторений

Цель: открыл LearnOS — сразу видно, что делать дальше, и одной кнопкой начинаешь. Курс выглядит как доска
задач (как bridge, только для человека). Повторения видны и запускаются из UI.
Зависит от: **B-004** (статусы items, review REST). Контекст: `docs/system-review-2026-11.md` §0, §3.

## Готово, когда
- [ ] `/` показывает «Сегодня», а не сетку KB.
- [ ] На «Сегодня»: продолжить (активная сессия / следующий элемент активного курса / незаконченная книга),
      повторения на сегодня (число + кнопка), входящие KB (число + ссылка), последние источники в обработке/с ошибкой.
- [ ] Каждый пункт — кнопка, которая ведёт к действию (сессия по элементу / чтение главы / чат-повторение).
- [ ] Страница курса — колонки или группы по статусу `todo / doing / read / done`; у элемента кнопки
      «Начать сессию», «Читать», «Прочитал сам». Добавить/удалить/переставить элемент из UI.
- [ ] `/review`: очередь повторений, кнопка «Повторить» открывает чат с интентом review по блоку.
- [ ] Бейдж «повторений сегодня» в навигации.
- [ ] Мобильная ширина 375px без горизонтального скролла.

## Изменения
1. **Сервер `GET /api/today`** (новый маленький модуль `modules/today/` только с api+service, читает через
   порты/сервисы других модулей): `{active_session, next_course_items[≤3], reading[≤3], review: {due_today},
   inbox_count, sources_attention[≤5]}`. Каждый пункт содержит `action: {kind, params}`.
2. **Сервер: старт сессии по элементу курса** — `POST /api/courses/{uid}/items/{id}/start` → создаёт разговор
   session-режима с `course_item_id` и возвращает `conversation_uid` (через chat-сервис, как сейчас делает
   intent session). Web переходит в разговор.
3. **Web `/` → `today/page.tsx`**: карточки секций; `kb` остаётся в навигации.
4. **Web курс-доска**: группировка по статусу, кнопки элемента, добавление элемента (поиск по источникам/главам/
   блокам), удаление, drag или стрелки для порядка (REST уже есть: add/remove/reorder).
5. **Web `/review`**: список из `GET /api/review/queue`, кнопка → новый разговор с интентом `review` и uid блока.
6. **Бейдж** повторений в `app-shell` из `GET /api/review/stats`.
7. Прогресс-бары — только `ui/progress.tsx`.

## Тесты
- server: `/api/today` на пустой базе и с данными; start по элементу создаёт разговор и связывает сессию.
- web: tsc/lint/build; ручная проверка в preview на desktop и 375px.

## Проверки
- `cd server && uv run ruff check . && uv run ruff format --check . && uv run lint-imports && uv run pytest`
- `cd web && npm run gen:api && npm run lint && npx tsc --noEmit && npm run build`

## Риски
- `today` не должен импортировать infra чужих модулей (контракт линтера) — только сервисы из контейнера.
- Цвета статусов — семантические токены (`web/DESIGN.md`), не hue.
