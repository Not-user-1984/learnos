# B-014 · Закрепление: карточки-суть, набор по книге, выжимка

Цель: прочитанное закрепляется коротко и по сути: 3–5 карточек на главу, повторение по одной карточке,
можно повторить только эту книгу. Дизайн: `docs/book-reading-flow.md` (шаг 5, правило «мякотки»). После B-013.

## Готово, когда
- [ ] У блока есть `cards: [{id, q, a}]` (в MD-frontmatter/теле и в индексе); генерируются при создании блока
      из сессии/главы: 3–5 штук, одна идея, ответ ≤2 предложения, только из проговорённого.
- [ ] Старые блоки: «Сделать карточки» на странице блока (генерация по требованию, не массово).
- [ ] SM-2 на карточку (`review_items` по `card_id`; блоки без карточек — как сейчас).
- [ ] Повторение карточек: страница `/review` показывает карточку → «Показать ответ» → оценка
      «Не помню / Трудно / Помню» (без LLM, быстро). Режим «объясни своими словами» через чат остаётся.
- [ ] Фильтр по источнику: `GET /api/review/queue?source=` и кнопка «Закрепить книгу» на странице книги.
- [ ] «Выжимка книги»: страница/вкладка книги — по главам: summary + карточки; экспорт в markdown.
- [ ] Карточки правятся/удаляются на странице блока (версия блока сохраняется).
- [ ] review_digest считает карточки.

## Точки входа
- Блок: `server/app/modules/knowledge/domain.py:85-101` (+ frontmatter `202-219`), агент block_writer (промпт — сжатость!).
- Повторения: `server/app/modules/review/` (`domain.py` SM-2, `service.py` `ensure_items` `27-43`, `on_session_finished`).
- Web: `web/src/app/review/page.tsx`, `web/src/app/library/[uid]/page.tsx`, `web/src/components/kb/block-page-client.tsx`.
- MCP: `get_review_queue` с `source`, `context` (B-007) отдаёт карточки.

## Проверки
- server: ruff/format/lint-imports/pytest; тесты: генерация (фейковый LLM) ≤5 карточек, SM-2 по карточке,
  фильтр по источнику, миграция review_items.
- web: lint/tsc/build; preview: книга → «Закрепить книгу» → 3 карточки → оценки → due сдвинулся.
