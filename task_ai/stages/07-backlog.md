# Этап 7 — Бэклог (после MVP)

Не начинать без отдельного согласования с пользователем. Каждый пункт перед стартом раскрывается в отдельный файл этапа в том же формате (цель, задачи, критерии приёмки, отчёт).

| Тема | Суть | Задел в архитектуре |
|---|---|---|
| Семантический поиск | sqlite-vec + эмбеддинги (роль `embed` в `llm.yaml`), гибрид FTS + векторы для `search` и контекста тьютора | модуль `search`, события индексации |
| Граф знаний | `@xyflow/react`: узлы — понятия и блоки, рёбра — связи, цвет по категории, клик → страница | `block_links`, понятия из [этапа 8](08-upgrades.md) A |
| Повторения в чате | полноценная review-сессия в веб-чате по нескольким блокам подряд (базовое SM-2 + Telegram — в [этапе 8](08-upgrades.md) C) | модуль `review` |
| Мультиагентность | агент как инструмент (`delegate_*`), оркестратор курса, внешние MCP-серверы как инструменты агентов | `AgentRegistry`, `run_structured`, `parent_run_id` |
| Песочницы | LXC-клоны на Proxmox (`pve.py`), `sandbox_exec` с подтверждением, code-server/ttyd с мобилки | `practice_step.machine`, профиль машин |
| Веб-статьи | источник `web`: readability-извлечение → главы по заголовкам | `library`, скилл-ингест |
| Другие провайдеры | `anthropic.py`, локальные модели (Ollama) для `fast` | `LLMProvider`, `llm.yaml` |
| Выбор моделей в UI | редактирование ролей в Настройках | `ModelRouter` |
| Переезд в облако / на хомлаб | выбор хостинга, перенос `data/` и `kb/`, домен и HTTPS, мониторинг; для хомлаба — NPM-роут, Tailscale, решение по сну сервера | Docker, prod-режим и бэкапы из [этапа 10](10-settings-and-cloud.md) F |
| D2 и Excalidraw | D2 — для схем объектов/архитектуры, если Mermaid окажется недостаточно красивым; Excalidraw — ручная доработка блок-схем (mermaid → excalidraw) | секция «Визуалы» и `VisualRenderer` из [этапа 9](09-visuals.md) |
| Ручной редактор MD | правка блока в вебе (CodeMirror) с версией | `update_block`, `block_versions` |
