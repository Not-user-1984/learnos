# 06 — Интерфейс

Стек уже есть: **Next.js 16 (App Router) + React 19 + TypeScript strict + Tailwind CSS v4 + react-markdown + mermaid + zod**, типы API — `openapi-typescript` (`npm run gen:api`). Остаёмся на нём и добавляем бесплатные библиотеки ниже.

## Визуальный стиль

Ориентиры: Linear, Notion, NotebookLM — спокойно, плотно, читабельно.

- **Тема:** тёмная по умолчанию (база `zinc`), светлая — полноценная. Токены цветов — CSS-переменные shadcn в `globals.css`.
- **Акцент:** один основной (`violet`), плюс цвета категорий из `kb/categories.yaml` (`sky`, `emerald`, `amber`, `rose`, `violet`, `zinc`) — полоска/точка категории на карточках.
- **Карточки:** радиус 12–16px, тонкая рамка `border`, лёгкий фон `bg-card`, ховер — подсветка рамки. Без тяжёлых теней.
- **Типографика:** текст блоков — `prose` с шириной ≤ 72ch, межстрочный 1.7; заголовки секций блока — с иконкой lucide (понятия — `book-open`, тезисы — `list`, «как я понял» — `lightbulb`, схема — `workflow`, практика — `terminal`, дозакрепить — `alert-triangle`, связи — `link`, источники — `library`).
- **Состояния:** скелетоны при загрузке, пустые состояния с подсказкой следующего шага («Загрузи первую книгу»), тосты (`sonner`) на действия.
- **Адаптивность:** работает с телефона (Pixel 9): сайдбар → `sheet`, правая панель чата → вкладка/`sheet`, карточки в одну колонку.
- **Доступность:** фокус-кольца, `aria-label` у иконок-кнопок, контраст AA.

## Экраны

### 1. Чат — `/chat`, `/chat/[uid]`

```
┌ разговоры ┐┌──────────── лента сообщений ────────────┐┌── контекст (resizable) ──┐
│ поиск     ││ ассистент: markdown + mermaid + код      ││ Источник: K8s in Action  │
│ • Сессия  ││   ▸ Читаю главу 3 (свёрнутый tool-чип)   ││ Глава 3: Поды            │
│ • Разбор  ││ ┌ карточка «Вопрос 2/5» ───────────────┐ ││ Сессия: ●Теория ●Вопросы │
│ • Свобод. ││ └──────────────────────────────────────┘ ││   ○Практика ○Разбор      │
│           ││ ┌ карточка команды [mac] ──────────────┐ ││ ⏱ 14 / 30 мин            │
│           ││ │ $ kubectl get pods -A        [копир.]│ ││ Понятия: 5/5 ✓           │
│           ││ │ kubectl — CLI · get pods — … · -A —… │ ││ Слабые места: 1          │
│           ││ │ Ожидаем: … · риск: низкий            │ ││ [Пропустить практику]    │
│           ││ │ [Вставить вывод]                     │ ││ [Завершить]              │
│           ││ └──────────────────────────────────────┘ ││                          │
│           ││ [режим: Свободный|Разбор|Сессия] [📎] [✈]││                          │
└───────────┘└──────────────────────────────────────────┘└──────────────────────────┘
```

- Новый разговор: выбор режима (сегментированный `toggle-group`) и, для `quick`/`session`, источника и главы (`command`-поиск по библиотеке). Можно начать без источника (`free`).
- Композер: авто-растущий `textarea`, Enter — отправить, Shift+Enter — перенос; кнопка 📎: загрузить PDF / вставить YouTube-ссылку (создаёт источник и job, в ленте — карточка `job` с прогрессом); кнопка «Стоп» во время генерации.
- Сообщения ассистента стримятся (SSE, см. 04); Markdown рендерится тем же компонентом, что и блоки, но с ленивым mermaid (рендер после завершения блока кода).
- Вызовы инструментов — компактные свёрнутые чипы с русским `label`; раскрытие показывает краткий результат.
- Карточки (`card` из SSE) — отдельные компоненты: `QuestionCard` (выделенный вопрос, счётчик), `EvaluationCard` (✓ понял / ◐ частично / ✗ не понял + комментарий), `CommandCard` (бейдж машины, моноширинная команда, копирование, разбор по частям, риск цветом, кнопка «Вставить вывод» → открывает поле для вывода, отправляется как сообщение с code-fence), `ChapterSummaryCard`, `BlockSavedCard` (превью блока + «Открыть» + выбор категории: «Принять предложенную» / «Изменить»), `BlockUpdatedCard` («v3 → v4», «Посмотреть», «Откатить»), `JobCard` (прогресс-бар).
- Правая панель (shadcn `resizable`; на мобилке — `sheet`): контекст активности и прогресс сессии (степпер по состояниям из события `session`), таймер, быстрые действия.

### 2. База знаний — `/kb`

```
┌ категории ────────┐┌ [поиск…] [теги ▾] [источник ▾] [тип ▾] [статус ▾] [сорт ▾] [▦/☰] ┐
│ 📥 Входящие   3   ││ ┌▌ Инкапсуляция в Python ──┐ ┌▌ Сетевая модель подов ───┐     │
│ ▾ Программирование││ │ Скрываем состояние…       │ │ У пода свой IP…          │     │
│   ▾ Python    12  ││ │ #python #oop  📖 Fluent…  │ │ #k8s  📖 K8s in Action    │     │
│     ООП        4  ││ │ урок · 13 окт · ⚠ 1       │ │ урок · 6 окт              │     │
│ ▸ Инфраструктура  ││ └───────────────────────────┘ └───────────────────────────┘     │
│ ▸ Личное          ││                                                                │
└───────────────────┘└────────────────────────────────────────────────────────────────┘
```

- Дерево категорий (collapsible), счётчики включают подкатегории; клик — фильтр. Цвет и иконка категории из YAML.
- **Входящие** — блоки с неподтверждённой категорией: на карточке «Агент предлагает: Программирование / Python / ООП» + [Принять] [Выбрать другую].
- Фильтры (в URL через nuqs): поиск (FTS), теги (мультивыбор), источник, тип (`урок`/`конспект`), статус (`входящие`, `есть «дозакрепить»`), период. Сортировка: новые, старые, обновлённые, по алфавиту, по источнику, «больше дозакрепить». Вид: сетка / список.
- Карточка блока: цветная полоска категории, заголовок, summary (2 строки), теги, иконка источника (книга/видео) + название, тип, дата, индикатор ⚠ (число слабых мест), версия если > 1.
- Страница категории `/kb/c/[...path]`: подкатегории, блоки, источники, из которых есть блоки в этой категории, курсы этой категории.

### 3. Блок — `/kb/[uid]`

- Шапка: крошки категории, заголовок, summary, бейджи (тип, дата, сессия, версия, категория — с подтверждением, если `suggested`).
- Тело: секции блока как раскрывающиеся карточки (открыты по умолчанию; состояние запоминается): **Ключевые понятия** — сетка мини-карточек «термин → определение»; **Тезисы**; **Как я это понял** — выделенная цитата; **Схема** — mermaid во всю ширину, клик — полноэкранный просмотр с зумом; **Практика** — нумерованные шаги в стиле `CommandCard` (только чтение); **Дозакрепить** — callout `WARNING`; **Связи** — `[[blk_…]]` рендерятся как чипы-ссылки с заголовком (hover-card с summary); **Источники** — ссылки на страницу источника и главу.
- Правая колонка (на мобилке — снизу): оглавление, метаданные, действия: **Обсудить в чате** (новый `free`-разговор с блоком в фокусе), **Повторить сессией** (session по той же главе), **Скопировать MD**, **Скачать .md**, **История версий** (список версий; просмотр версии; «Откатить к этой»).

### 4. Библиотека — `/library`, `/library/[uid]`, `/library/[uid]/[chapter]`

- Сетка источников: «обложка» — градиент цвета категории + иконка вида (книга/видео/статья) + название; автор/канал; прогресс (глав разобрано / всего); статус обработки (бейдж + прогресс job).
- Кнопка «Добавить источник»: `dialog` с вкладками **PDF** (dropzone), **YouTube** (URL), **Статья** (URL — бэклог, вкладка неактивна с подписью «скоро»).
- Страница источника: обзор (summary), список глав — номер, заголовок, summary, key points (раскрываются), статус главы (не начата / быстрый разбор / пройдена сессией), блоки из главы (чипы). Действия на источник: **Пройти по книге** (активность → разговор `quick` с курсора), на главу: **Быстрый разбор**, **Сессия**, **Читать**.
- Читалка главы: текст главы (prose, Shiki для кода), навигация пред./след., кнопка «Обсудить этот фрагмент» (выделенный текст → новый разговор с цитатой).

### 5. Курсы — `/courses`, `/courses/[uid]`

- Карточки курсов: название, тема, категория, прогресс (элементы пройдены / всего), «Продолжить».
- Страница курса: упорядоченный список элементов (источник целиком / глава / блок) с отметками прохождения, перетаскивание для порядка (можно кнопками ↑↓ в v1), «Следующий шаг» — кнопка, открывающая нужный разговор.
- «Новый курс»: вручную (название + добавление из библиотеки/базы) или **«Собрать агентом»**: тема → `course_planner` предлагает план из библиотеки + найденных источников (`research_sources`) → пользователь отмечает, что берёт → курс создан.

### 6. Настройки — `/settings`

- **Профиль железа:** список машин (карточки), добавить/редактировать: имя, тип (`macos`, `linux`, `proxmox`, `windows`, `other`), характеристики, установленные инструменты (теги), заметки.
- **Обучение:** длительность сессии, число понятий в теории, вопросов на понятие, практика по умолчанию, стиль объяснений.
- **Модели:** роли (`chat`, `structured`, `fast`) → провайдер/модель (только чтение в v1), статус ключа (есть/нет, без значения), «Проверить соединение».
- **Категории:** дерево с переименованием, цветом, иконкой, порядком (пишет `kb/categories.yaml`).
- **MCP:** URL-ы (`/mcp`, `/mcp/<module>`), пример конфига для opencode (копировать).
- **Обслуживание:** «Переиндексировать базу знаний», «Экспорт всего».

## Компонент Markdown

Один компонент `web/src/components/markdown/Markdown.tsx` для блоков, глав и сообщений чата:

- pipeline: `remark-gfm` → `remark-github-blockquote-alert` → `remark-math` → свой `remarkWikiLinks` (`[[blk_x]]` → ссылка на `/kb/blk_x` с заголовком из переданной карты uid→title) → `rehype-katex` → Shiki (`@shikijs/rehype`) для кода;
- `language-mermaid` → компонент `Mermaid` (клиентский, ленивый импорт, тема из next-themes, при ошибке синтаксиса — показать исходник и плашку «схема не отрисовалась»);
- обёртка `prose dark:prose-invert` с настроенными цветами ссылок/кода/цитат;
- у блоков кода — кнопка «копировать» и подпись языка.

Существующие `Markdown.tsx`/`Mermaid.tsx` — переработать в этот компонент.

## Данные на фронте

- Server Components по умолчанию; клиентские компоненты — только где интерактив (чат, фильтры, диалоги).
- Типы — только из `src/types/api.ts` (сгенерированы); ручные типы — лишь для SSE-событий и карточек (zod-схемы в `src/lib/chat/events.ts`, валидируют каждое событие).
- Клиент SSE: `src/lib/chat/stream.ts` — `fetch` + `ReadableStream`, парсер `event:/data:`, `AbortController` для «Стоп».
- Мутации — Server Actions или `fetch` к API + `router.refresh()`.
