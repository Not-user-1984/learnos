# Идеи из Hermes Agent (эталон самонастраивающегося агента)

Источник: https://github.com/nousresearch/hermes-agent (MIT, Nous Research). Что берём в LearnOS:

1. **Персона — файл, а не код** (SOUL.md у Hermes). У нас — `prompt.md` каждого агента; рантайм читает файл при каждом запуске → правка применяется без рестарта. Override-копии в `data/prompts/` переживают пересборку Docker (том).
2. **Шлюз в мессенджеры** (gateway на Telegram и др.). У нас — модуль `messenger`: Bot API + прокси, отправка текста/блоков/глав книги; везде один порт `TelegramGateway`.
3. **Цикл самоулучшения с подтверждением**: агент предлагает изменение (дифф в карточке чата) → человек approves → применяется; история изменений с откатом. У Hermes — approval-паттерны команд; у нас — approval промптов (а с этапа T-012 — и конструктор агентов).
4. **Самодостаточность**: всё внутри проекта (прокси-логика, мост, промпты) — разворачивается в любом окружении без глобальных скиллов мака.
5. Позже (бэклог): агентные скиллы, создаваемые после сложных задач; cron-автоматизация доставкой в Telegram.

## Из полного ресёрча 2026-10-17 (детали: [reference/hermes-research.md](reference/hermes-research.md))

6. **Truncate-and-store**: полный текст страницы — на диск/в библиотеку, агенту — head+tail окно + способ дочитать середину. Фундамент для веб-статей как источников.
7. **Grounded citations**: ледджер источников со стабильными id; дословная цитата отвергается кодом, если её нет в сохранённом тексте; блок Sources генерируется механически. Fact-checking конспектов без LLM.
8. **Provider-реестр поиска**: единый контракт вендоров + автовыбор по ключам + keyless-ring rescue + single-flight TTL-кэш.
9. **Delegate-подагенты**: дети с чистым контекстом и урезанными инструментами, родитель видит только summary — параллельный research без раздувания контекста.
10. **Браузер как третья линия** (после search/extract): a11y-tree снапшоты с refs вместо скриншотов; сессии на задачу; SSRF до navigate и на редиректах.
11. **Насыщение research-цикла**: стоп, когда >80% результатов уже видели (обычно 2–3 раунда breadth-then-depth) — stopping-критерий для агента-ресёрчера.
