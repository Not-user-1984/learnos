# BUG-005 — подозрение: окно 2ч в active_runs не фильтрует старые запуски

**Статус:** open (подозрение из кода, не проверял тестом) · 2026-10-28

## Наблюдение

Запуск 870 создан 15:07. В ~18:30 (возраст 3ч20м) agent_state仍然 показывал
`working: true` с этим запуском — хотя `active_runs` должен ограничивать
свежесть двумя часами (ACTIVE_RUN_MAX_AGE).

## Подозрение

`_parse_iso(created_at)` (строка с '+00:00', aware) сравнивается с
`self._clock.now()` (возможно naive локальное) — смешение aware/naive или
часовых поясов рвёт фильтр. Либо фильтр вообще не сработал из-за исключения,
проглоченного выше по стеку.

## Проверить при починке

Юнит-тест: запуск возрастом 3ч в status=running → active_runs пуст.
Заодно: сравнение времени в recorder привести к одному типу (UTC naive).
