# BUG-001 — «Да» карточки action_offer без обратной связи; дубли

**Статус:** open · найдено 2026-10-28 · свидетельство: разговор `cnv_0f56eb84`

## Симптом

Пользователь нажал «Да» на карточке «Добавить стартовые видео в Библиотеку?» —
видимой реакции нет. Нажал ещё 3 раза: в разговоре 4 одинаковых user-сообщения
«Да — делай…» (15:07:06, 15:08:01, 15:08:05, 15:08:53), **ни одного ответа**
ни на одно.

## Что происходит (по agent_runs)

- Первый клик создал запуск 870 (15:07:06) — живёт часами, работает.
- Повторные клики **не создают запусков вообще** — тихо, без ошибки, без
  тоста, без пояснения «агент уже работает». Для пользователя это «всё упало».

## Корни (предположительно)

1. Кнопка карточки шлёт обычное сообщение; нет disable/дебаунса.
2. stream_reply при активной генерации разговора, видимо, отщёлкивается
   (или гонка `_running`), ответ не ставится в очередь и не объясняется.
3. Каждое повторное отправленное сообщение остаётся в истории навсегда.

## Чинить (когда возьмём)

- Кнопка карточки: disable после клика + «отправлено, агент работает».
- stream_reply при занятом разговоре: либо очередь (дождаться и ответить),
  либо явная ошибка SSE + инлайн-подсказка в UI.
- Для карточек: согласие слать с маркером offer_id, чтобы дубль схлопывался.
