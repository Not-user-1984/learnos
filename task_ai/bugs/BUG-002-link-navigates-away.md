# BUG-002 — клик по ссылке уводит со страницы, меню спрятано

**Статус:** fixed в [T-044](../archive/2026-10-28-T-044-chat-incident-fixes.md) · найдено 2026-10-28 · воспроизведено на проде

## Симптом (слова пользователя)

«Нету всплывающего меню, когда нажимаю на ссылки — он перекидывает».

## Воспроизведение

Разговор `cnv_0f56eb84`: ссылка «Суть 1С программирования за 25 минут» —
площадь клика по тексту ~321px, кнопка «Действия со ссылкой» (шеврон) — **18px**.
Клик по тексту = обычная навигация <a> — страница уходит на YouTube; меню
живёт только на крошечном шевроне, который пользователь не заметил.

## Фикс (T-044)

Клик по тексту ActionLink-ссылки (YouTube/PDF) — `preventDefault` + открытие меню
действий; первый пункт — «Открыть в новой вкладке». Модификаторные клики
(Ctrl/Cmd/Shift/Alt) идут нативно — привычное «открыть в новой вкладке» с клавиатурой
работает. Обычные ссылки не тронуты, шеврон остался дублирующим триггером.
