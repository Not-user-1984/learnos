# BUG-009 — PDF без закладок (TOC) валил ингест книги

**Статус:** fixed → [T-053](../archive/2026-11-04-T-053-incident-torrent-bookfix.md) · найдено 2026-11-03 · свидетельство: «Django-4-Практика создания» (791 стр., get_toc() пуст) — 4 упавших jobs, source src_09a3ec0d в failed; book-splitter отвечал «PDF без закладок (TOC) — эвристика по заголовкам пока не реализована»

## Корень

`server/skills/book-splitter/run.py` строил главы исключительно по закладкам
PDF; их отсутствие = отказ. Сканы и PDF «из ворда без разметки» — обычное дело
для русских техкниг с трекеров.

## Чинить

Fallback-нарезка по страницам: без TOC главами становятся куски по N страниц
(дефолт 50, зажим 10..200), «Страницы 1–50», …; концевой кусок < 5 стр. входит
в предыдущую главу. В ответе `mode: toc|pages`; в pages-режиме куратор
структуры не вызывается. Рендер/чистка/картинки — общий путь.

**Сделано (T-053):** `_page_chunks` + ветка в `main()`; gate куратора в
`LibraryService._run_process`; тесты (23-стр. PDF без TOC, clamp, формула
791→16). На проде src_09a3ec0d переобработан: 16 глав на 791 стр.
