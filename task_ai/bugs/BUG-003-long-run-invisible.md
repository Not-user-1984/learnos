# BUG-003 — часовой запуск без понятного прогресса и управления

**Статус:** fixed в [T-044](../tasks/T-044-chat-incident-fixes.md) (частично; см. «Отложено») · найдено 2026-10-28 · свидетельство: запуск 870 (cnv_0f56eb84; отработал за 7 мин, ответ сохранён — пользователь об этом не узнал)

## Симптом

«Добавь видео» — агент работал ~7 минут (24 шага, 26 вызовов, 2 видео добавлены,
ответ сохранён), но в UI: только бейдж «агент работает: root ·
шаг N». Не видно: что именно он делает (какое видео, какой инструмент), нет
кнопки «Остановить» из этого состояния, нет частичного текста. Вернувшись
позже, пользователь видит «висит и ничего не происходит».

## Смежное

- Частичный прогресс агента не сохраняется — текст ответа появится только
  в конце (для многочасовых цепочек это «пустота» на всё время).
- Действия с jobs (транскрипция/саммари) не видны в разговоре.

## Фикс (T-044)

- `agent_runs.current_tool` (миграция 0011): рантайм пишет label текущего
  инструмента при каждом вызове; `agent_state.runs[].current` отдаёт его в detail
  разговора, бейдж показывает «агент работает: root · шаг N · <что делает>».
- Рядом с бейджем кнопка «Остановить» — вызывает существующий
  `POST /api/conversations/{uid}/stop` (работает и когда генерация живёт
  в фоне независимо от вкладки).

## Отложено (кандидаты в idea-бэклог)

- Промежуточный текст агента в БД (стрим в сообщение-черновик) — на многошаговых
  цепочках пользователь видит «пустоту» до финала.
- Верхняя граница длительности одного запуска + авто-отчёт «сделал X из Y,
  продолжить?».
- Действия с jobs (транскрипция/саммари) в ленте разговора.
