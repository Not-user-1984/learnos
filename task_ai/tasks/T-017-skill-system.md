## Что нужно

Ресёрч — первый скилл, увиденный пользователем как скилл. Обобщить: скиллы — дроп-ин
возможности агентов, видимые из всех каналов (веб-чат, MCP, Telegram), с UI управления.
Основа — паттерны Hermes (см. [reference/hermes-research.md](../reference/hermes-research.md)),
заточенные под ресёрч и обучение: система должна уметь сама себя чинить и улучшать
(скилл можно отредактировать из чата после неудачного прогона).

## Что уже есть (фундамент)

- `server/skills/<name>/` (SKILL.md + run.py) — drop-in, видны из всех каналов; сейчас их три:
  web-search, book-splitter, youtube-to-summary.
- Конструктор агентов (T-012): промпты правятся словами из чата, кастомные агенты создаются LLM.
- Ресёрч как состояние чата (T-014): research-флаг → директива в system_extra, не в сообщениях.

## Состав (этапы)

1. **Реестр скиллов + прокидывание агентам**: SKILL.md парсится в реестр; агентам доступен
   инструмент `use_skill(name, args)` (или декларативное подключение в AgentSpec.tools).
   Скилл = промпт + опционально run.py + объявленные инструменты.
2. **UI в настройках**: список скиллов (встроенные/кастомные), раскрытие содержимого,
   правка текста словами (как у агентов), включение/выключение для агентов.
3. **LLM-конструктор скиллов**: «хочу скилл, который…» → драфт SKILL.md → тестовый прогон → апрув.
4. **Самопочинка**: после падения прогона агент предлагает фикс скилла (диф в чате, апрув юзера),
   история версий скилла в БД.
5. **Ресёрч-скилл формально**: перенести research-директиву в скилл `research` (SKILL.md),
   включая правила насыщения; research-флаг остаётся точкой входа из UI.

## Критерии готовности

- [ ] скилл виден и запускаем из чата, MCP и Telegram одинаково
- [ ] кастомный скилл создаётся из UI словами и переживает пересборку (БД + data/)
- [ ] правка скилла из чата с апрувом и историей
- [ ] research оформлен как скилл, поведение не регрессировало (тесты T-014 зелёные)

## Заметки

Порядок 1→2→5 закрывает пользовательский запрос (ресёрч = скилл), 3–4 — «система улучшает
сама себя». Не раздувать: скилл ≠ плагин с кодом на проде; run.py опционален и песочницей
по умолчанию не является (код скиллов — часть репо, кастомные — промпт+инструменты).
