## Что нужно

Сейчас аналогии — часть дефолтного стиля ответов (захардкожены в промпте
root-агента, см. BUG-007). Пользователь хочет:

- убрать аналогии из вывода по умолчанию — ответы короче и по делу;
- кнопка «Аналогия» у блока/фрагмента: нажал — агент коротко объясняет это
  место через аналогию (с учётом актуального профиля из «О себе»).

## Зависимости

- Сначала [BUG-007](../bugs/BUG-007-profile-about-ignored.md): профиль
  «О себе» должен реально попадать в промпты — иначе аналогии по кнопке
  будут такими же «девопсерскими».

## Критерии готовности

- [ ] Дефолтный вывод агентов без аналогий (промпты, тест на отсутствие
      директивы аналогий).
- [ ] Кнопка «Аналогия» на блоках разбора/сессии — короткий ответ-аналогия
      в том же разговоре.
- [ ] Аналогия учитывает «О себе» из профиля.

## Заметки

- Взять после BUG-007 и T-045/T-046 — здесь нужен механизм «кнопка → короткое
  действие над блоком», который естественно появится после T-045.
