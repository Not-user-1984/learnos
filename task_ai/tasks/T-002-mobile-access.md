## Что нужно
Роут `learn.not-user-1984.duckdns.org` создан в NPM, но снаружи недоступен: порты 80/443 не проброшены на роутере, а Tailscale на PVE-хосте разлогинен (Funnel не работает). Нужен стабильный путь с Pixel 9 (уже в tailnet).

## Варианты (решить с пользователем)
1. `tailscale up` на PVE-хосте + subnet routing (`--advertise-routes=192.168.0.0/24` + approve в админке) — мобилка видит весь LAN, включая 192.168.0.132:3000.
2. Проброс 80/443 → 192.168.0.107 в UI TP-Link (руками) + автoupdate DuckDNS (сейчас запись статична, IP динамический).

## Критерии готовности
- [ ] выбранный вариант настроен и проверен с мобильной сети
- [ ] инструкция «как открыть LearnOS с мобилки» — в README корня
