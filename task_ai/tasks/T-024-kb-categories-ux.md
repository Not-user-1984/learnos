## Что нужно

Стек правок по категориям в базе знаний (только веб, сервер не трогаем):

1. **Скрываемая правая колонка на странице блока** (`/kb/[uid]`): категория, действия, версии, метаданные. Сворачивание в узкую полоску с кнопкой-переключателем тем же методом, что левый сайдбар категорий на `/kb` (`useStored`, состояние в localStorage). Иконки `right_panel_close` / `right_panel_open`.
2. **Поиск по категориям**:
   - фильтр-поиск в дереве категорий на `/kb` (живая фильтрация по title/path, совпавшие узлы с родительской цепочкой, авто-раскрытие, заглушка при пустом результате);
   - переиспользуемый `CategorySelect` с фильтром по вводу вместо обычного Select в двух местах: страница блока и «Входящие».
3. **Баг: после смены категории блока список `/kb` показывает старое** («без категории», счётчик «Входящие: N»). Корень клиентский — staleness при возврате на `/kb` (Router Cache/bfcache). Фикс: dirty-флаг в localStorage при мутации категории + клиентский компонент на `/kb`, который при монтировании видит флаг и делает `router.refresh()`.
