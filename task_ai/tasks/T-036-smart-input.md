## Что нужно

Корневой агент «видит» контент сообщения без смены режима: претрекер распознаёт
ссылки/типы контента, PDF вкладывается прямо в чат, агент предлагает действие
карточкой. Работаем в ветке `t-034-orchestrator` (см. T-034).

1. **Претрекер на входе сообщения** (`ChatService.stream_reply`, до агента, без LLM):
   - распознавание: YouTube-ссылка, произвольный URL, arXiv-id/DOI, тема-как-текст
     (эвристики достаточно, regex);
   - результат — структурированная заметка в `system_extra`: «В сообщении
     YouTube-ссылка X. Доступные действия: add_source(kind=video, url=X) →
     process_source»; аналогично для URL-статьи и т.п.;
   - длина контента сообщения не режется претрекером (он только добавляет контекст).
2. **Вложения `attachments` в `MessageIn`**: PDF-файл → `upload_pdf` (существующий
   путь), в сообщение агенту добавляется заметка «Пользователь приложил PDF
     "…", источник uid=…, доступные действия: process_source, главы, разбор».
   Upload происходит до запуска агента, агент оперирует готовым source_uid.
3. **PDF в композере чата** (веб): кнопка вложения реально принимает PDF
   (сейчас тост «на странице Библиотеки»), показывает чип вложения до отправки.
4. **Карточки предложений**: обобщение существующего механизма карточек — тип
   `action_offer` (заголовок, описание, 1–2 кнопки «Да/Нет»), согласие
   отправляется как обычное сообщение (паттерн `note_draft`). Промпт root-агента:
   при распознанном контенте сначала предложить действие, не выполнять молча.
5. **Скиллы видны агентам**: устранить промах из аудита — `torrent_fetch`
   обещан `RESEARCH_DIRECTIVE`, но отсутствует в `free_chat.tools`
   (`chat/service.py:49` vs `chat/agents.py:17-41`); выдать root-агенту и
   free_chat инструменты скиллов (`run_skill` + имена скиллов).

## Критерии готовности

- [ ] api-тест: сообщение с YouTube-ссылкой → в system_extra агенту попадает
      заметка с распознанным типом и доступными действиями.
- [ ] api-тест: сообщение с attachments=[pdf] → источник создан, агенту пришёл
      source_uid, ответ не падает.
- [ ] Веб: PDF вкладывается в композере, чип вложения, отправка с вложением
      работает; карточка предложения отображается и кнопка «Да» отправляет ответ.
- [ ] Проверки зелёные; коммиты в ветке; после готовности — «ждёт ревью ZCode».

## Заметки

- Претрекер — чистая функция над текстом сообщения (unit-тест без БД).
- Веб-статьи: pretrecker распознаёт URL, добавление источника kind=web делает
  агент — вкладка «Статья (скоро)» в upload-dialog умирает в T-039.
