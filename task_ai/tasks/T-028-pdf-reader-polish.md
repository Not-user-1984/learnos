## Жалобы пользователя

1. **Мыльно во встроенном режиме** (не на весь экран): canvas рендерится в CSS-пикселях без devicePixelRatio, на retina (DPR=2) растягивается ×2.
2. **Переходы глава→глава нестабильны** («не всегда переключаются, паршится»): вероятна гонка ленивого рендера со скроллом к цели + неточность высот плейсхолдеров (высота по 1-й странице), быстрые повторные клики во время загрузки документа теряются.
3. **«В новой вкладке» — голый файл**: всегда с 1-й страницы, без кнопок.

## Решение

**A. Один PdfViewer** (без копий):
- чёткость: рендер в физическом разрешении (`canvas.width = css × dpr`, `transform=[dpr,…]`, css-размеры канвасу), порог `dpr ≥ 1`, перерендер с дебаунсом при любом изменении scale (зум и resize);
- детерминированный `jump-to-page`: очередь последнего намерения (применяется и когда документ ещё грузится), прыжок = отрендерить коридор вокруг цели → скорректировать высоты холдеров по факту → скролл; ленивый режим возвращается после;
- слоты тулбара (`toolbarStart`/`toolbarExtra`), опциональная клавиатура.

**B. Полноэкранный ридер** `/library/{uid}/read?ch=N&page=M` (server-light, client):
- листание стр.± кнопками и ← → / PgUp / PgDn, глава в индикаторе вычисляется по текущей странице (границы глав не блокируют листание);
- зум +/− и «по ширине», «стр. N / M»;
- яркость: CSS filter brightness на контейнере, слайдер, localStorage;
- оглавление-шторка: главы с номерами страниц (из /outline), клик — переход, текущая подсвечена;
- пред/след. глава кнопками; «оригинальный .pdf» — вторичная ссылка;
- открытие с page из URL, иначе со стартовой страницы главы; место живёт в URL (replaceState без перезагрузки).

**C. Встроенный режим** в читалке — тот же компонент: чёткость + надёжные переходы; «В новой вкладке» открывает полноэкранный ридер с текущего места (ch + page).

## Критерии готовности

- [x] Воспроизведение зафиксировано: (1) мыльность — кодом: в renderPage devicePixelRatio не используется вообще (canvas в CSS-px, style.width не задаётся) — на DPR=2 растяжение ×2; IAB-окружение имеет DPR=1, численного автодоказательства не даёт, корень кодовый.
