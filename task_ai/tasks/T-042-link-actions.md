## Что нужно

Агент в чате показывает ссылки (YouTube-видео из поиска, PDF-книги из ресёрча
и трекеров, arXiv). Сейчас это мёртвый текст. Нужны быстрые действия прямо
по ссылке — главная фишка: **быстрый разбор открывается в новом разговоре**
(нашёл в ресёрче → клик → новый root-разговор уже работает с материалом).

1. **Сервер: `POST /api/sources/from-url`** `{url}` — скачать и добавить в
   источники одним действием: YouTube → add_source(kind=video)+process_source;
   прямая PDF-ссылка (http…/*.pdf или content-type application/pdf после HEAD/
   первых байт) → скачать в temp → существующий upload_pdf-путь (процессинг
   книг стартует сам); прочий URL → add_source(kind=web)+process_source.
   Лимит размера (например 200 МБ), таймаут, ошибки — понятные. Ответ —
   карточка-результат для UI (source uid/kind/status).
2. **Веб: ActionLink в markdown-рендере** (`components/markdown`) — рендер
   ссылок http(s): обычные остаются ссылками; YouTube-URL и .pdf-URL получают
   кнопку-шеврон/иконку → **попап-меню**:
   - «Открыть в новой вкладке»;
   - «Добавить в источники» (→ /api/sources/from-url, тост с результатом);
   - «Быстрый разбор» — создаёт НОВЫЙ root-разговор, первое сообщение — сама
     ссылка + `intent=review` (претрекер T-036 уже даёт агенту заметку с
     действиями) — переход в новый разговор, агент начинает разбор.
   Для PDF вместо «Быстрый разбор» — «Изучить книгу» (тот же новый разговор,
     intent=study; если источник ещё не обработан — агент сам предложит
     обработать, карточкой).
3. **Промпт root** не менять: меню — чистый UI-слой поверх того, что агент
   уже показывает; ссылка в тексте остаётся ссылкой.

## Критерии готовности

- [ ] api-тесты: from-url с YouTube-ссылкой (video-источник+job), с PDF-URL
      (файловый источник через upload-путь, маленький фикстурный PDF по http
      — поднять локальный http-сервер в тесте), с превышением лимита/битым
      URL — ошибки внятные.
- [ ] Веб: ActionLink с попапом (токены DESIGN.md, фокус/клавиатура, закрытие
      по Esc/клику мимо), «Быстрый разбор» открывает новый разговор с
      intent=review и ссылкой; lint+tsc+build зелёные.
- [ ] Сервер: линты/тесты зелёные.
- [ ] Ветка `t-042-link-actions`; «ждёт ревью ZCode».

## Заметки

- Меню — малый поповер, не диалог; на мобиле — тот же поповер от кнопки.
- Проверка «это PDF»: расширение .pdf ИЛИ content-type по первым байтам
  (Stream первые ~1 КБ HEAD/GET), чтобы ловить ссылки трекеров без .pdf.
- Транскрибация видео и обработка PDF идут асинхронными jobs — from-url
  отвечает сразу (uid + статус), UI показывает тост «обрабатывается».
