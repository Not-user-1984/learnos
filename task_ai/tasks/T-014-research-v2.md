## Что нужно
Качественный ресерч источников по теме: устойчивый поиск, сохранение найденного в библиотеку,
проверяемые утверждения. Собирается из топ-5 паттернов Hermes (см. референс).

## Состав (по этапам внутри задачи)

1. **research-модуль: провайдеры поиска** — `SearchProvider` ABC + реестр (DDGS keyless, SearXNG self-hosted, Tavily по ключу), автовыбор по наличию ключей, keyless-rescue при падении, single-flight TTL-кэш (20 мин).
2. **Извлечение страниц → библиотека (truncate-and-store)**: extract по URL → readability-чистка → полный текст = источник kind=web в библиотеке (документ с постраничным `read_chapter`); в контекст — head+tail окно; base64-свип, бинарный детект, SSRF-проверки. Закрывает [T-011](T-011-web-articles.md).
3. **Агент-ресёрчер**: диалог «найди лучшие источники по теме X» → breadth-then-depth, stopping-критерий насыщения (>80% повторов → стоп), выдача: кандидаты с аннотациями → выбор пользователя → добавление в библиотеку.
4. **Grounded citations**: таблица «утверждение конспекта → источник → дословная цитата», дословная проверка кодом по тексту главы в библиотеке, `[unverified]` для непроверяемого, блок Sources генерируется механически. Связка с превью конспекта (note_draft).
5. **Delegate-подагенты**: research-агент спавнит детей по направлениям (доки/статьи/видео/форумы), родитель видит только summary (в рантайме — суб-run с `parent_run_id`).

## Критерии готовности
- [ ] поиск работает без платных ключей (keyless-цепочка), с кэшем
- [ ] URL → статья в библиотеке, читается постранично, экспорт в конспект
- [ ] research-диалог останавливается по насыщению, кандидаты на апрув
- [ ] конспект содержит цитаты, проверенные дословно по сохранённым текстам
- [ ] тесты на кэш/single-flight, verify цитат, SSRF
