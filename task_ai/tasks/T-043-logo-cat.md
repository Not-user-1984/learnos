## Что нужно

Три части на одной ветке. Юмор — фирменный, чуть дерзкий (примеры от
пользователя ниже), это личный продукт.

### 1. Логотип + слоган на приветствии (`chat-start.tsx`)

- **Логотип**: инлайн-SVG маскот-кот (минималистичный линейный силуэт, один
  акцентный цвет — `text-primary`, ~56px), рядом вордмарк **LearnOS**
  (Literata, medium). SVG — свой простой (уши-хвост в 2–3 path), не копия
  чужого лого; селектор не нужен.
- **Вращающиеся фразы** под приветствием (одна на заход, случайная):
  - «Тут скиллы прокачивают человеческие скиллы»
  - «Учимся всерьёз, но не по-взрослому»
  - «Твой личный Harness для прокачки мозга»
  - «Знания приживаются здесь»
  - «Сессия 30 минут — блок в базе навсегда»
  Список — константа в `lib/format.ts` рядом с подписями (или локально в
  chat-start), рандом на монте.

### 2. Кот-питомец, гуляющий по блокам чата

Спрайт уже в репо: **`web/public/oneko.gif`** (256×128, кадры 32×32, сетка 8×4).
Источник анимации — известный oneko (MIT, adryd325/oneko.js); в комментарии
компонента укажи происхождение и лицензию.

Новый компонент `web/src/components/chat/chat-cat.tsx`:

- Рендерится внутри ChatView поверх области сообщений (absolute, z над
  сообщениями, не мешает кликам — pointer-events только на самом коте);
- **Кадры** (background-position кратно 32): бег вправо x=0..1 y=2? — сверся
  с картой: idle (-3,-3), alert (-7,-3), бег влево столбцы 2–5 строки y=2? —
  точная карта из oneko.js: `idle:[[-3,-3]], alert:[[-7,-3]], scratchSelf:
  [[-5,0],[-6,0],[-7,0]], sleep:[[-3,1],[-4,1]], бег вправо: [[0,0]..[3,0]] и
  [[4,1]..[7,1]]?` — НЕ угадывай: возьми карту из
  https://raw.githubusercontent.com/adryd325/oneko.js/main/oneko.js
  (spriteSets), зеркальный бег влево — CSS scaleX(-1).
- **Поведение**: кот ходит по «полке» — горизонтальной полосе у нижней границы
  видимой области сообщений (внутри скролл-контейнера, едет вместе с ним);
  каждые 3–8 с меняет состояние: идёт влево/вправо 1–4 с → стоп (idle) →
  иногда чешется/спит; при клике по коту — **пузырь с фразой**.
- **Фразы кота** (пузырь 2–4 с, стек фраз пополняй в том же духе, без мата
  сильнее приведённого):
  - «Мы чё там, пиздюк, изучаем?»
  - «Давай грохнем алгоритмы»
  - «Почитаем Кнута, долбоёб?»
  - «Сессия сама себя не пройдёт»
  - «Опять прокрастинация? Я одного мурчания от разочарования»
  - «Забей: я посплю на твоих незакреплённых блоках»
  - «Ты учишь — я гуляю. Deal.»
- **Выключалка**: маленькая иконка-кнопка рядом с котом (или в шапке чата)
  скрыть/показать, состояние в localStorage; `prefers-reduced-motion` — кот
  сидит idle и мурлычет фразы по клику (без ходьбы).
- На стартовом экране (пока нет сообщений) кот тоже жив — гуляет по полке
  карточки-инпута.

### 3. Мелочи

- Кот не появляется в режиме сессии с практикой? — нет, пусть живёт всегда в
  ChatView и на ChatStart; НЕ рендерить в настройках/библиотеке.
- Производительность: rAF-цикл с фоном кадров ~8 fps (setInterval 125 мс),
  снимок состояния — useState, никакого ре-рендера сообщений.

## Критерии готовности

- [x] Приветствие: SVG-маскот + вордмарк + случайная фраза; три темы чистые
      (SVG на currentColor, вордмарк на var(--font-serif) — красится темой).
- [x] Кот: ходит по полке, зеркалится, idle/сон/чёс, пузырь по клику с фразами,
      выключалка с localStorage, prefers-reduced-motion.
- [x] Кот жив и на стартовом экране, и в разговоре; не перекрывает клики
      (кроме себя).
- [x] web: lint + tsc + build зелёные; визуальную полировку делает ZCode.
- [x] Ветка `t-043-logo-cat`; **ждёт ревью ZCode**.

  div 32×32, image-rendering: pixelated.
- Фразы — отдельная константа, чтобы пополнять без логики.
- **Статус: ждёт ревью ZCode** (коммит `5152d01`, ветка `t-043-logo-cat`,

    TAGLINES, ленивый useState + suppressHydrationWarning против
    hydration-мисматча); `web/src/components/chat/chat-cat.tsx` — новый

    relative + ChatCat.
  - Карта кадров взята из spriteSets оригинала oneko.js (idle -3,-3; alert

  - Веб-тестраннера в проекте нет — проверка по критерию задачи lint+tsc+build;
    сервер не трогался.
  - Фразы кота дополнил в духе ТЗ: «Мурчание на частоте закрепления памяти»,
    «Фейнман бы одобрил. Я — посмотрю», «Курсы сами себя не соберутся,
