# Бах-бах-Репорт — входящие баги и фичи

Сырой inbox наблюдений из живого тестирования LearnOS. Пишет скилл
`.zcode/skills/bah-bah-report` (ZCode) по фразам «запиши баг-репорт» / «запиши идею фичи»:
он интерпретирует слова пользователя, коротко разбирается в коде (read-only) и кладёт
запись сюда. В момент записи ничего не исполняется и не исправляется.

Когда накопится — «запусти бах-бах на исправление»: open-записи группируются по областям
кода (без пересечений по файлам) и последовательно уходят агенту learnos-dev.

Статусы: `open` (записано) → `tasked` (взято в работу) → `fixed` (ссылка на задачу/коммит).
Связь с реестрами: известные баги — `bugs/BUG-…`, задачи — `../tasks/`; ссылки на них живут
в поле «Связано», записи дублируются в реестры только при фазе исправления.

## Фичи

### BB-001 · feature · fixed · 2026-11-04 · «Прочитал сам»: кнопка самостоятельного чтения главы

- **Идея:** главы, которые пользователь читает сам (предисловие, введение — «нечего
  разбирать с нейронкой»), должны помечаться прочитанными кнопкой и засчитываться
  в прогрессе книги, без разбора агентом.
- **Зачем:** сейчас курсор книги двигает только агент (`mark_chapter_done` в разговоре
  разбора); самостоятельно прочитанные главы выпадают из прогресса, и полоса книги
  врёт.
- **Куда приляжет:** кнопка в читалке рядом с «Обсудить главу» — `web/src/components/library/reader.tsx:219`;
  индикатор пройденных глав в списке — `web/src/app/library/[uid]/page.tsx:73-146`
  (активность уже запрашивается); сервер — `server/app/modules/learning/service.py:45`
  (`start_activity` идемпотентен, R-11 — get-or-create) и `:404` (`mark_chapter_done`,
  курсор только вперёд). Прогресс чата (`_review_progress`, `chat/service.py:649`)
  подхватит курсор автоматически.
- **Связано:** —
