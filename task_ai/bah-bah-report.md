# Бах-бах-Репорт — входящие баги и фичи

Сырой inbox наблюдений из живого тестирования LearnOS. Пишет скилл
`.zcode/skills/bah-bah-report` (ZCode) по фразам «запиши баг-репорт» / «запиши идею фичи»:
он интерпретирует слова пользователя, коротко разбирается в коде (read-only) и кладёт
запись сюда. В момент записи ничего не исполняется и не исправляется.

Когда накопится — «запусти бах-бах на исправление»: open-записи группируются по областям
кода (без пересечений по файлам) и последовательно уходят агенту learnos-dev.

Статусы: `open` (записано) → `tasked` (взято в работу) → `fixed` (ссылка на задачу/коммит).
Связь с реестрами: известные баги — `bugs/BUG-…`, задачи — `../tasks/`; ссылки на них живут
в поле «Связано», записи дублируются в реестры только при фазе исправления.
