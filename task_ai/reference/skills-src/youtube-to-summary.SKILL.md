# youtube-to-summary

Из YouTube-ссылки получает **полный текст видео** и делает **саммари** (главная суть,
ключевые тезисы).

## Пайплайн

1. Тулза `tools/youtube_to_text.py` достаёт текст:
   - сначала субтитры (ручные, затем авто) в языках `ru → en`;
   - если субтитров нет — скачивает аудио и транскрибирует через Whisper API
     (нужен `OPENAI_API_KEY`, расходуется ~$0.006/мин — предупреждай о длинных видео).
2. Агент читает текст и пишет саммари (см. формат ниже).

## VPN (важно!)

YouTube и OpenAI (Whisper) на этой машине ходят через VLESS-нод. Тулза **автоматически**
детектит локальный SOCKS5 `127.0.0.1:7890` (mihomo / Clash Party) и пускает через него
`yt-dlp` и запросы к Whisper API. Если прокси не нужен — флаг `--no-proxy`.

- Если порт 7890 не слушается → Clash Party не запущен. Попроси пользователя запустить
  Clash Party (профиль mihomo-telegram), детали — в скилле `mac-vpn`.
- Признак отсутствия прокси: yt-dlp зависает на metadata / Whisper отдаёт таймауты.

## Запуск

```bash
python3 ~/my_dev/radmipa-skills/tools/youtube_to_text.py "<URL>" --stdout
```

- `--stdout` — текст сразу в вывод (для коротких видео, основной режим).
- Без флага — Markdown-файл в `~/scrin_video/output/` (для длинных видео; читай файл частями).
- `--lang ru,en` — приоритет языков субтитров (default).
- `--force-whisper` — игнорировать субтитры, всегда транскрибировать аудио.
- Whisper-режим печатает прогресс чанков по 10 минут в stderr — ждите спокойно.

## Формат саммари (агент пишет сам)

```
## Суть одним абзацем
2–4 предложения: о чём видео и главный вывод.

## Ключевые тезисы
- 5–10 пунктов, каждый — законченная мысль с контекстом.

## Выводы / что делать
Итоговые рекомендации автора, если есть.
```

Саммари — на языке пользователя, независимо от языка субтитров. Если видео длинное
(> 30 мин текста) — саммари делай по секциям видео. После саммари можно приложить
полный текст, если пользователь просил «весь текст».

## Зависимости

- `yt-dlp` (brew), `ffmpeg`/`ffprobe`, python `requests`.
- `OPENAI_API_KEY` в `~/.config/opencode/.env` — только для Whisper-fallback.

## Источник

Логика извлечения субтитров взята из `~/my_dev/StadiaAi/backend/app/services/youtube_parser.py`
(проверено в бою), Whisper-часть — из `tools/video_to_text.py`.
