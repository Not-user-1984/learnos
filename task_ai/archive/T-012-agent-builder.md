## Что нужно
1. В настройках агенты раскрываются: виден текущий промпт и инструменты (поведение).
2. После апрува правок (tuning) раскрытие показывает актуальный текст.
3. Конструктор новых агентов из UI: пожелание словами → LLM-драфт (имя/описание/промпт/инструменты) → создание; агент сразу доступен всей системе (режим чата `agent:<name>`).
4. Удаление только кастомных агентов; встроенные защищены.

## Критерии готовности
- [x] раскрытие карточек агентов (промпт + инструменты + бейджи custom/настроен)
- [x] конструктор: POST /tuning/agents/draft (agent_designer) → превью с правками → создание
- [x] кастомный агент в реестре без рестарта, режим чата agent:<name>, survives restart (БД)
- [x] удаление кастомных (409 на встроенных), разговоры с удалённым агентом не падают (fallback free_chat)
- [x] правки кастомных через tuning-чат применяются в БД; «Изменить» в UI (PATCH)
- [x] миграция 0005, тесты api (полный цикл), 115 зелёных

## Заметки
Таблица custom_agents; AgentSpec.prompt_text (промпт из строки); AgentRegistry.upsert_custom/remove_custom;
загрузка кастомных после миграций в lifespan.
