## Что нужно

Англоязычные PDF качаются в библиотеку как есть (оригинал не трогаем, главы остаются на английском — агенту нужен оригинал). Но диалог с нейроном (быстрый разбор, сессия-урок, конспекты глав) — всегда на русском, автоматически.

### Э1. Язык книги при обработке
- book-splitter (`server/skills/book-splitter/run.py`) при process определяет язык текста: доля кириллических символов в сэмпле (несколько тысяч символов из середины первых глав) → `meta.lang = "ru" | "en"` (прочее — не задаём или "other"; для наших целей бинарно ru/не-ru достаточно).
- Язык пишется в `sources.meta.lang` (meta уже есть; видео пишет lang аналогично — `library/service.py:373`).
- У существующих источников без lang — NULL, трактуем как ru/неопределено.

### Э2. Директива в контекст диалога
- Блок «Контекст» чата (`app/modules/chat/service.py`, строки ~334-388, где «Текущая глава N»): если источник книги с `meta.lang` != "ru" — добавить строку вида: «Язык материала: английский. Общение, разборы и объяснения — всегда на русском; оригинальные цитаты приводи с переводом».
- Промпты quick_reviewer и сессионного агента (`app/modules/chat/agents/quick_reviewer/prompt.md` и сессионный): универсальная строка «Язык диалога — русский, независимо от языка книги» (работает и без контекст-строки, контекст-строка усиливает для en-книг).

### Э3. Саммари глав на русском
- chapter_summarizer (`app/modules/chat/agents/chapter_summarizer/prompt.md`): саммари и key_points всегда на русском, даже для английских глав (агент-тул уже гоняет его после сплита).
- source_overviewer — аналогично (обзор книги на русском).

### Э4. read_chapter не трогаем
Оригинальный текст глав остаётся как есть (английский) — перевод только в генерации агентов, не в хранилище.

## Критерии готовности
- [ ] После обработки en-книги `sources.meta.lang == "en"`; у ru-книг — "ru".
- [ ] Quick-разговор по en-главе получает в системном контексте директиву русского (проверить в тесте сборки контекста).
- [ ] Саммари en-главы — на русском (юнит-тест промпта/вызова с моком LLM или проверка на проде).
- [ ] Переингест одной en-книги на проде + живой quick-разбор отвечает по-русски (смоук вручную: первый ответ агента на «начнём разбор главы N» — русский).
- [ ] Тесты: определение языка (ru/en/mixed сэмплы), контекст-строка для en, отсутствие для ru. Все проверки зелёные, деплой.

## Заметки
- Тестовая en-книга: залить маленький англоязычный PDF (можно препринт arXiv как kind=book) — после деплоя; живой смоук делает закрывающий агент или пользователь.
- Не заводить перевод хранилища/глав — только генерация.
- У видео уже есть lang в meta — переиспользовать ту же директиву для en-видео (бонус, если тривиально).
