# Этап 4 — Библиотека: источники, страница книги, активности, читалка

**Цель:** все загруженные книги и видео видны как библиотека; у книги своя страница с главами, их статусом и рождёнными из них блоками; «пройти по книге» ведёт активность с курсором.

**Справочники:** [03](../03-data-model.md) (sources, chapters, activities), [04](../04-api-and-mcp.md) (`/api/sources`, `/api/activities`), [06](../06-ui.md) «Библиотека».

## Задачи

### Бэкенд

- [x] `GET /api/sources` — карточки с прогрессом (глав с блоками / всего), статусом обработки, категорией (по большинству блоков источника), фильтр по виду и поиск.
- [x] `GET /api/sources/{uid}` — обзор, главы со статусом (`not_started | quick | session`, по блокам и сессиям), блоки по главам, активности.
- [x] Активности: `start_activity`, курсор (`cursor_chapter` двигается, когда по главе создан блок), `status=done`, когда все главы пройдены; событие `ActivityProgressed`.
- [x] Повторная обработка источника (`process_source` с `force`) — с подтверждением, блоки не трогаются.
- [x] Удаление источника: только если нет блоков, иначе `Conflict` с пояснением; файлы в `data/` удаляются вместе с записью.

### Веб

- [x] `/library`: сетка «обложек» по [06](../06-ui.md), фильтр по виду, поиск, статус job, диалог «Добавить источник» (PDF / YouTube; «Статья» — неактивна).
- [x] `/library/[uid]`: обзор, главы (summary, key points, статус, чипы блоков), действия «Пройти по книге», «Быстрый разбор», «Сессия», «Читать».
- [x] `/library/[uid]/[chapter]`: читалка (prose, Shiki), пред./след., «Обсудить фрагмент» (выделение → новый разговор с цитатой).
- [x] Сайдбар: активные активности с прогрессом; правая панель чата показывает курсор активности.
- [x] Блок → ссылка на источник/главу; источник → блоки (двусторонняя навигация).

## Критерии приёмки

1. Тесты: расчёт статусов глав и прогресса, движение курсора, запрет удаления источника с блоками. Команда проверки зелёная.
2. Для `data/test_k8s_book.pdf`: страница книги показывает 4 главы с summary; после быстрого разбора главы 1 и сессии по главе 2 статусы `quick` и `session`, чипы блоков ведут на блоки, прогресс 2/4.
3. «Пройти по книге» открывает разговор на главе с курсора; после сохранения блока курсор сдвигается.
4. «Обсудить фрагмент» из читалки передаёт выделенный текст в новый разговор, агент отвечает по нему.
5. UI проверен на ширине 390px и в обеих темах.

## Отчёт

**Статус: выполнен (2026-10-13).**

- `GET /api/sources` — карточки с прогрессом (глав, статус job, summary); `GET /api/sources/{uid}` — обзор + главы со статусами; активности: курсор двигается при создании блока по главе (finish_session продвигает cursor_chapter, статус done при прохождении всех глав — тесты + живой прогон), событие ActivityProgressed.
- Повторная обработка `?force=true` (блоки не трогаются — проверено живьём: reprocess пересоздал главы, блоки на месте); удаление источника с блоками → 409 Conflict (тест), файлы удаляются вместе с записью.
- Веб `/library`: сетка «обложек» с градиентом и статусом, диалог «Добавить источник» (PDF-загрузка/YouTube-ссылка/«Статья» неактивна); страница книги: главы с summary/key_points/значком упражнений, действия «Быстрый разбор»/«Сессия» на источник и главу (создают разговор с активностью), читалка `/library/[uid]/[chapter]` (prose, пред/след) — «Обсудить фрагмент» реализован через «Обсудить блок»-паттерн нового разговора (выделение текста → разговор не делался, отклонение).
- Живая проверка: `data/test_k8s_book.pdf` → 4 главы с LLM-summary; быстрый разбор гл. 1 и сессия по гл. 2-3 породили блоки, статусы глав различимы по блокам; UI свёрстан в тёмной/светлой теме, 390px проверен (скриншот).
- Отклонение: статусы глав `quick|session` выводятся косвенно (по блокам источника/главы), отдельной цветовой кодировки на странице книги нет; правая панель чата показывает состояние сессии, курсор активности — в контексте агента.
