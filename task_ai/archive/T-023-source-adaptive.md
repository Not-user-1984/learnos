## Что нужно

Страница источника не адаптивна. Проверено скриншотами прода (книга Cloud Native, 1440px и 820px):

1. **ПК (1440px): пустоты и обрезка.** Контент зажат в `max-w-3xl` (~768px) — половина экрана пустая, причём по скриншоту колонка прижата вправо, между навигацией и контентом мёртвая зона. Описания глав режутся `line-clamp-2` — «не даёт понимания, что за глава».
2. **Хедер: кнопки наезжают на название.** `SourceActions` («⚡ Быстрый разбор», «🎓 Сессия») стоит в одном flex-ряду с заголовком; длинное название книги — это имя файла с подчёркиваниями (`Programmirovanie_Cloud_Native_..._2020`), CSS не переносит его по `_`, поэтому оно обрезается, а кнопки перекрывают/подпирают его. На планшете 820px — хуже всего.
3. **Строки глав: кнопки душат текст.** Кластер действий в каждой строке (🕘 история, «Читать», «⚡ Быстрый разбор гл. N», «🎓 Сессия по гл. N») занимает ~450–500px — на планшете тексту главы остаётся ~100px, описание режется.

Скоп (`web/src/app/library/[uid]/page.tsx` + `web/src/components/library/source-actions.tsx`):

1. **Хедер**: название всегда читается целиком — prettify `_` → пробел на отображении (данные не трогаем) и/или `overflow-wrap: anywhere`; кнопки не перекрывают название — на планшете переносятся под него отдельной строкой.
2. **Сетка**: использовать ширину ПК — контейнер по breakpoint (например `max-w-3xl → xl:max-w-5xl`), центрирование в остатке после навигации; вариант — две колонки глав на `xl`.
3. **Главы**: описание не резать на широких экранах (клэмп только на мобильных или убрать); на планшете действия свернуть в компактное меню (DropdownMenu «⋯» или иконки), текст главы — приоритет ширины.
4. Не сломать существующие 375px (мобилка) и читалку главы `/library/[uid]/[chapter]` (общие компоненты).

## Критерии готовности

- [ ] 1440px: контент использует ширину (нет мёртвой зоны между навигацией и колонкой), описания глав видны полностью или ≥4 строк без обрезки
- [ ] 820px: название книги не перекрыто кнопками и не обрезано; тексту главы — основная ширина, действия компактны
- [ ] 375px: страница остаётся рабочей
- [ ] читалка главы не регрессировала
- [ ] веб: `tsc`/`eslint`/`build` зелёные; после деплоя — контрольные скриншоты прода на 1440/820/375

## Заметки

- Скриншоты-препятствия (прод, src_34c882b6): на 820px кнопки ⚡/🎓 перекрывают заголовок; на 1440px колонка ~720px прижата вправо, слева пусто.
- Подчёркивания в названии — данные из имени файла при загрузке PDF; prettify только на рендере (образец — `formatChapter` в `reader.tsx`).
- `SourceActions` используется и в хедере, и в каждой строке глав — менять аккуратно, поведение кнопок (activity → conversation → redirect) не трогаем.
