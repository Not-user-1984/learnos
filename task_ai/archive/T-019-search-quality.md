## Разведка (2026-10-18, сеть пользователя)

Живые пробы с мака: DDG (html и lite) — 202 + anomaly-капча; Bing HTML — отдаёт мусорную выдачу без
кук, Bing RSS — пусто; Mojeek — Captcha; Ecosia — 403; searx.be — заглушка; Semantic Scholar — 403
(датацентровые IP). Стабильно работают ключлесс-API: **Wikipedia (MediaWiki search), Hacker News
(Algolia), arXiv (Atom XML)**.

## Сделано

- [x] `ChainProvider` (паттерн Hermes keyless-rescue): провайдеры по очереди до первого непустого
      ответа, падение звена не роняет цепочку, полная пустота — слияние всех результатов.
- [x] Провайдеры `WikipediaProvider`, `HackerNewsProvider`, `AcademicProvider` (arXiv).
- [x] Платные — рабочий код с автовключением по ключу: `TAVILY_API_KEY` (LLM-поиск, 1000/мес free)
      или `SERPER_API_KEY` (Google-выдача, 2500 free на старте) — попадают в начало цепочки.
- [x] Инструмент `academic_search` у free_chat/quick_reviewer/session_tutor + правило в промптах:
      фундаментальная/научная тема → arXiv к веб-поиску.

## Ключик (рекомендация пользователю)

Завести бесплатный ключ **Tavily** (tavily.com, 1000 кредитов/мес) или **Serper** (serper.dev,
2500 запросов) → `sec set TAVILY_API_KEY ...` → прокинуть в docker-compose → поиск станет
Google-качества без капч. Код уже включит сам по наличию ключа.
