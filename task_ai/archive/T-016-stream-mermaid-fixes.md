## Что было

1. **Mermaid-бомбы.** Красные блоки «Syntax error in text / mermaid version 12.1.0» копились внизу
   страницы при каждом стриминговом ответе со схемой. Причина — не «сломанные схемы» и не браузер:
   во время стриминга незакрытый ` ```mermaid `-блок уходит в `mermaid.render()` обрубком, render
   бросает исключение, но **оставляет error-контейнер в document.body**. Схема в итоге дописывается
   и рендерится нормально, а мусор от промежуточных попыток остаётся навсегда (у юзера в Яндексе
   просто больше всего живых стримингов).
2. **«Не дождался ответа».** Юзер отправил «сделай ресёрч» в разгар авто-деплоя: `learnos-web`
   пересоздавался, SSE-соединение умерло, фронт делал один немедленный fetch (тоже в умерший
   прокси) и замолкал навсегда — без ошибки и без ответа. Ядро при этом дописало ответ в БД
   («Ресёрч готов: прочитал две статьи…», ран 23 `max_steps` — отдельная история: лимит шагов
   free_chat, ответ сохранён).

## Сделано (0cece21)

- `Mermaid.tsx`: `suppressErrorRendering: true` (mermaid 12.1.0 — проверено в песочнице: исключение
  бросается, error-блок в body не создаётся) + страховочная чистка `div[id^="dmmd-"]`.
- `chat-view.tsx`: при стриминге незакрытый ` ``` `-блок срезается (`trimOpenFence`) — обрубки
  схем/кода вообще не уходят в рендер, нет мигания плашки.
- `chat-view.tsx`: обрыв стрима (деплой/сеть, не «Стоп») → poll `/api/conversations/{uid}` каждые 3с
  до 3 минут с индикатором «связь прервалась — догоняю ответ агента…»; ответ подтягивается, как
  только ядро его допишет. Если не дописал — плашка с «Повторить». AbortError (кнопка Стоп) и
  error-события агента poll не запускают.

## Проверка

- Песочница (CDN mermaid 12.1.0): render бросает на битых схемах; с suppress — мусора в body нет.
- Прод e2e: тестовый free-чат, живой стриминг со схемами gRPC — 0 «Syntax error», 0 error-дивов,
  схемы отрисованы; чат юзера cnv_a8506c89 — обе старые схемы ОК, мусора нет. Тестовый разговор удалён.

## Не делалось (сознательно)

- Латинизация кириллических id узлов в ремонте схем: реальные схемы LLM пишет валидными (кавычки,
  латинские id — промпты уже просят), падали только стриминговые обрубки.
- Рост max_steps free_chat (12 шагов на ресёрч-цикл): лимит осмыслен, ответ при исчерпании
  сохраняется и доезжает до юзера через done.
