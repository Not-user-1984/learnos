## Что нужно

«Я жму читать, и там кнопочка — я вижу чистую PDF, какая она есть: встроенная читалка/просмотрщик, эффект книги, картинки не теряются». Текущая читалка (переработанный текст) остаётся как есть — это дополнение для чтения литературы по программированию.

## Сделано

**Сервер** (модуль library, fitz уже в зависимостях):

- `GET /api/sources/{ref}/file` — оригинальный PDF: `FileResponse` inline, `application/pdf`; starlette 1.7 отдаёт `Accept-Ranges: bytes` и 206 по Range (проверено — длинные книги стримятся). 404: не-книга, нет local_path, нет файла на диске, источник не найден.
- `GET /api/sources/{ref}/outline` — стартовая страница каждой главы: закладки PDF (тот же TOC, из которого book-splitter строил главы; верхний уровень, как в сплиттере) матчятся с главами по нормализованному title (пробелы/регистр); промахнувшаяся глава стартует со страницы предыдущей найденной, при пустом результате — 1. Кэш по source_id в памяти, инвалидация при reprocess (`_run_process`) и удалении источника.

**Веб:**

- `reader.tsx`: переключатель «Конспект | PDF» в хедере (только для kind=book; иконки `auto_stories`/`picture_as_pdf`, role=tablist). PDF-режим: `<iframe src="/api/sources/{uid}/file#page={N}">` (нативный вьюер, через next-прокси `/api`), под iframe полоска навигации «пред/след. глава» (ссылки несут `?mode=pdf`, страница обновляется по закладкам) + счётчик «глава N · страница M». Контролы шрифта/гарнитуры в PDF-режиме скрыты, рядом ссылка «В новой вкладке» (заглушка для окружений без встроенного вьюера). Режим запоминается (`useStored`, ключ `learnos-reader-mode`), `?mode=pdf` применяет режим разово при монтировании.
- `[uid]/page.tsx`: у каждой главы рядом с «Читать» кнопка «PDF» (только book) → `{idx}?mode=pdf`.
