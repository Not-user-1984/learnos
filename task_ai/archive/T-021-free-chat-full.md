## Сделано (97c7130)

- **Кнопки в free-чате** (раньше только в quick): «Закрепить пройденное» (вопросы по материалу
  разговора), «Конспект в базу знаний» (превью → апрув), «Собрать курс».
- **«Собрать курс»**: тема разговора (без префикса «Ресёрч:») → POST /courses/plan (планировщик
  видит источники, добавленные ресёрчем, и блоки БЗ) → /courses/from-plan → редирект на курс
  (сессии + прогресс). Пустой план → тост-подсказка, без ошибки.
- **youtube_search**: каскад yt-dlp ytsearch (35с таймаут) → web-цепочка `site:youtube.com` →
  web-цепочка «…видео youtube»; инструмент у free_chat/quick_reviewer/session_tutor + правила
  в промптах («видео → youtube_search, добавляй kind=video в Библиотеку»).

## Проверка

- Прод: кнопки в свободном чате юзера (все три), планировщик собирает 6 пунктов курса из его
  реальных блоков/источников (Ansible, Helm, Cloud Native), youtube_search подключён всем агентам.
- YouTube из сети пользователя 2026-10-18 задросселирован целиком (yt-dlp не тянет ни поиск, ни
  конкретные видео — волна замедления; раньше обработка видео работала). Каскад оживёт сам;
  стабильный видео-поиск — ключ Tavily/Serper (T-019).
