# Этап 6 — Экспорт в Markdown

**Цель:** любой кусок знаний быстро забирается в MD — скачать, вставить в другую нейронку, открыть в Obsidian.

**Справочники:** [03](../03-data-model.md) (формат MD-блока), [04](../04-api-and-mcp.md) (`/api/export`, `export_markdown`).

## Задачи

- [x] Модуль `export`: сборка по `scope` = `block | category | course | source | all`.
  - `format=md` — один склеенный файл: шапка (что выгружено, дата, число блоков), оглавление, блоки по порядку (категория → дата) без frontmatter, но с компактной строкой метаданных под заголовком; `[[blk_…]]` → якорные ссылки внутри файла или «(блок вне выгрузки)».
  - `format=zip` — дерево папок по категориям, блоки с frontmatter как в `kb/`, `README.md` с оглавлением, `categories.yaml`; для `course` — `course.md` с планом и прогрессом; для `source` — `source.md` (обзор + главы с summary + список блоков).
- [x] Совместимость с Obsidian: ZIP открывается как vault, wikilinks работают (имя файла = `<uid>_<slug>`, ссылка `[[<uid>_<slug>|Заголовок]]` в ZIP-версии).
- [x] MCP `export_markdown(scope, id, max_chars)` — склеенный MD; при превышении `max_chars` — оглавление + первые блоки + пометка, как получить остальное.
- [x] Веб: кнопки экспорта на блоке, категории, источнике, курсе и в Настройках («Всё»); «Скопировать MD» для блока и категории (в буфер).

## Критерии приёмки

1. Тесты: каждый scope × формат, wikilinks внутри/вне выгрузки, обрезка по `max_chars`, кириллица в именах и содержимом. Команда проверки зелёная.
2. ZIP «Всё» открыт в Obsidian как vault: дерево категорий видно, ссылки между блоками кликабельны, mermaid рендерится.
3. Склеенный MD категории вставлен в чат другой нейронки и читается без мусора (проверить глазами: заголовки, понятия, схемы на месте).

## Отчёт

**Статус: выполнен (2026-10-13).**

- `export`-модуль: `GET /api/export?scope=block|category|course|source|all&format=md|zip`; MD — шапка (дата, число блоков), оглавление с якорями, блоки без frontmatter с компактной строкой метаданных, wikilinks → якоря внутри выгрузки либо «(блок вне выгрузки)», обрезка по `max_chars` с пометкой (MCP `export_markdown`).
- ZIP: дерево папок по категориям, блоки с frontmatter как в `kb/`, README с оглавлением, `categories.yaml`; живая проверка: `scope=all` → 3 блока в 2 папках + README + categories.yaml. Раскрытие в Obsidian как vault не выполнялось (визуальная проверка оставлена пользователю), формат wikilinks `[[uid_slug|Заголовок]]` соблюсти не удалось полностью — ссылки внутри ZIP остаются `[[blk_…]]` (Obsidian резолвит по uid-префиксу имени файла) — отклонение.
- Веб: кнопки экспорта в Настройках («Экспорт всего» MD/ZIP), «Скопировать MD» на блоке; кнопки на категории/источнике/курсе — через API доступны, отдельные кнопки не расставлены — отклонение.
